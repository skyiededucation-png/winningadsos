Module 02

Ads Generation

独立的做图工具：锁定 Logo，贴上现成的文案和主视觉，一次出几十张低清草稿。挑中的出 Variants，满意的 Upscale 成正式图。

1

Logo

Logo 和公司资料锁定之后，每一张图都会带上，才可以开始放 Content。
2

Content

一行 = 一张图。只放图上的字（最多 5 组）；长的 MEAT 写成 Caption: 不会上图。照 Design Skill v2。
ID风格家族图上文字（Tag / Hook / Highlight / Body / Offer / CTA）主视觉（一个物件 / 场景）图
3  批量出草稿 0 张低清草稿
4

挑草稿 → Variants / Upscale

点图打开大图；右上角圆圈 = 选中。选中的可以一次 Upscale。
5

Finals

Upscale 完成的正式图，自动编 Creative ID，存在 output/finals/。点右上角圆圈勾选。
任务

设定

OpenAI API

网上版本：API key 放在 Vercel 的环境变量 AI_API_KEY（不会出现在网页里）。换别家 API：改上面的网址和模型名。

模型

比例跟着品牌设定（默认 3:4，gpt-image-2 系列出 1056×1408）。xhigh 只有 2.5 系列支持。

Content 模型（文字）

用 OpenAI Responses API，同一把 key。规则照 docs/CONTENT-SKILL.md，每次生成都会重新读，改了档案就生效。

清空工作区

删掉做图区所有内容行、草稿和正式图档案。品牌、设定、Content Campaign 都会保留。

Prompt 模板

{{on_image}} 图上文字 · {{highlight}} 重点词 · {{twist}} 每张的创意点子 · {{family}} 风格方向 · {{visual}} 主视觉 · {{aspect}} {{logo_position}} {{image_roles}}
